# 桌面对齐与发布路线

状态日期：2026-11-18。桌面对照为 PC 1.6.12（`cc99ba3322c807aacb1a8716e0be7e8f7fd86f2a`），移动端范围为 P164。功能接入、工程互操作、像素一致、设备验收分别统计。

| 优先级 | 差距 | 完成标准 |
| --- | --- | --- |
| P0 | `.comp` v22 与工程功能覆盖。当前读取 v1–v21 和历史 v27 的受支持子集，按内容写 v17/v18；v22 及未支持的调整、效果、GIF、部分高位深组合不能当成已支持。 | 以 PC 创建的 v22 工程做打开、编辑、保存、跨端重开；覆盖未知字段、失败时保留原工程与不可编辑组合。 |
| P0 | 合成像素。仍有蒙版重采样、羽化、旋转/缩放选区、混合和高精度像素差异。Android 按目标尺寸直接求值，PC 对原尺寸合成图做重采样，导出缩放也需要独立比较。 | 固定真实跨端样本比较 CPU、GLES 与 PC，保留失败反例，逐项验证选区边界、半透明像素和复杂图层。 |

## 原生引擎公开路线

1. **当前：** Android 源码和可复核的预编译 `.so`。库与 JNI 绑定一起更新，校验两个架构和最终 APK 的载入条件。
2. **下一阶段：** 先固定公开 JNI 契约、项目互操作测试样本与像素测试。完成许可和源码边界复核后，按模块提供能独立构建的原生代码和主机 CI，预编译路径仍可选择。
3. **后续：** 已公开引擎可由固定工具链重建，发布记录关联源码版本、ABI、两架构哈希、对应测试和签名制品，再考虑默认使用源码构建。
