# 桌面对齐与发布路线

状态日期：2026-11-18。桌面对照为 macOS 1.6.12（`cc99ba3322c807aacb1a8716e0be7e8f7fd86f2a`），移动端范围为 P164。界面接入、工程互操作、像素一致和真机验收分别记录。当前调试包可以构建，测试 APK 已编译；当前公开包尚无真机端到端结果。

## P0：跨端兼容与真机可用性

| 优先级 | 差距 | 完成标准 |
| --- | --- | --- |
| P0 | `.comp` v22 与工程功能覆盖。当前读取 v1–v21 和历史 v27 的受支持子集，按内容写 v17/v18；v22 及未支持的调整、效果、GIF、部分高位深组合不能当成已支持。 | 以 PC 创建的 v22 工程做打开、编辑、保存、跨端重开；覆盖未知字段、失败时保留原工程与不可编辑组合。 |
| P0 | 合成像素。仍有蒙版重采样、羽化、旋转/缩放选区、混合和高精度像素差异。Android 按目标尺寸直接求值，PC 对原尺寸合成图做重采样，导出缩放也需要独立比较。 | 固定真实跨端样本比较 CPU、GLES 与 PC，保留失败反例，逐项验证选区边界、半透明像素和复杂图层。 |

## P2：性能与发布

| 优先级 | 差距 | 完成标准 |
| --- | --- | --- |
| P2 | 性能与正式发布。个别机型有八层 2048² 的历史容量证据，尚缺最终签名包的真实显示帧耗时、长时热稳定和设备矩阵。 | 用同一候选包测操作延迟、帧时间、内存、恢复、热稳定；确认签名备份和恢复，再完成商店审核。 |
| P2 | iOS。当前仅有独立起步工程，未包含在本仓库。 | 工具、图层、持久化、Metal 渲染与 iPhone/iPad 真机验收，之后再推进发行。 |

先固定跨端样本和真机回归流程，再逐项扩大文件与功能覆盖。每项功能以可编辑、可保存、可重新打开为基础，并单独记录跨端像素结果。正式发布使用同一签名候选包完成性能与稳定性验收。

## 原生引擎开源路线

1. **当前：** 公开 Android 源码、测试和两种架构的 `.so`。开发者可以直接打包，无需配置原生工具链。
2. **固定接口和测试：** 记录 JNI 版本、参数及错误约定，补齐工程互操作和像素测试素材。先明确模块依赖和第三方许可，再按具备独立构建条件的模块分批开源。
3. **提供可复现构建：** 每批源码一起发布固定工具链、构建脚本、主机测试和 Android CI。完整引擎可从公开源码构建后，再将源码构建设为默认；在过渡期继续保留 `.so` 打包选项。制品应关联源码提交、接口版本、两种架构哈希及测试结果。
